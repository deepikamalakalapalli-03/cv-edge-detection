# Edge Detection Using OpenCV

A Python-based image processing project that compares Sobel, Prewitt, and Canny edge detection techniques on a grayscale image.

## Features

- Sobel Edge Detection
- Prewitt Edge Detection
- Canny Edge Detection
- Visual comparison using Matplotlib

## Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib
- Google Colab

## How to Run

1. Open the Python file in Google Colab.
2. Upload the required image.
3. Update the image path if necessary.
4. Run all the cells.

## Output

The program displays the original grayscale image along with the results of Sobel, Prewitt, and Canny edge detection.
